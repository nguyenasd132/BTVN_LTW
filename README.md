## 🛠️ Yêu cầu môi trường & Công cụ
- **IDE:** Visual Studio 2022 (khuyến nghị v17.8 trở lên).
- **SDKs:** .NET 10.0 SDK & .NET Framework 4.7.2 / 4.8 Developer Pack.
- **Database:** Microsoft SQL Server 2019/2022 hoặc SQL Server Express, SQL Server Management Studio (SSMS).
